Mercadin Regional
Aplicativo/Site de pedidos para um comercio local (familiar). O cliene monta o pedido pelo sistema e o mercado recebe a solicitação para confirmar via Whatsapp/Telefone (MVP sem pagamento integrado).

Projeto desenvolvido como parte do Bootcamp de Java com Inteligencia Artificial do @Itaú, aplicando java + springboot no backend e práticas de QA (teste unitários, integração e API)

Status - Em andamento

Stack
Backend: Java + Spring Boot
Banco de dados: PostgreSQL
Frontend: a definir
Testes: JUnit, Mockito, MockMvc/RestAssured, Postman
